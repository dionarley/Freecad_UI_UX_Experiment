FreeCAD UI/UX Experiment

Laboratório de experimentos de interface para o FreeCAD

Sobre o projeto

Este repositório testa se o FreeCAD é viável para customizar a interface (esconder docks, aplicar QSS, menu contextual rápido, gerenciar docks, editar estilos ao vivo) e, se der certo, enviar melhorias para a comunidade.

por Dionatley R V — português nativo. "God And Odin Bless us!"

O que está neste repositório

ui_lab_probe.py

Script de "laboratório" de UI dentro do FreeCAD: lista docks, aplica layout/QSS, menu rápido (Ctrl+Shift+Space) e restaura o estado original. Nunca é modificado.

ui_lab_app.py

Aplicação real de UI/UX (não só teste): janela com abas de Docks, QSS/Estilo e Info/Controle, log integrado, ícone programático e configuração persistente.

window_test.py

Janela simples com botão de teste, compatível com o FreeCAD (dentro ou fora).

tests/

Testes automatizados com pytest (mínimo, não ocupa muito espaço em disco).

run.sh

Script de execução para sincronizar dependências, rodar testes e executar o app.

Dockerfile

Container mínimo (podman/docker) para rodar os testes.

Instalação rápida

cd /home/dionarley/codes-area/Freecad_UI_UX_Experiment
uv sync                 # dependências de dev (pytest)
uv sync --extra window  # + PySide6 (app e testes de janela)
uv run pytest -q        # rodar testes
./run.sh app            # executar o app real (standalone)

O projeto usa uv para dependências e mise para fixar o Python 3.11.

Como usar (dentro do FreeCAD)

1. ui_lab_probe.py

from ui_lab_probe import get_lab
lab = get_lab()
for item in lab.list_docks():
    print(item)
lab.apply_layout_and_qss()   # esconde docks + aplica QSS
lab.open_quick_menu()        # menu contextual (Ctrl+Shift+Space)
lab.restore()                # desfaz tudo

2. ui_lab_app.py (aplicação real)

from ui_lab_app import run_in_freecad
win = run_in_freecad()

Oferece três abas: Docks (mostrar/esconder docks), QSS / Estilo (editor ao vivo) e Info / Controle (recalcular documento, Fit All).

Modo standalone (fora do FreeCAD)

uv sync --extra window
uv run python ui_lab_app.py

Cria uma janela independente para desenvolver e testar a interface sem precisar do FreeCAD instalado.

Testes

uv run pytest -q

Saída esperada (sem PySide6): 3 passed in 0.01s.
Saída esperada (com PySide6 + libGL): todos os testes passam.
