FreeCAD UI/UX Experiment

Laboratório de experimentos de interface para o FreeCAD

UI/UX experiment laboratory for FreeCAD

Sobre o projeto About the project

Este repositório testa se o FreeCAD é viável para customizar a interface (esconder docks, aplicar QSS, menu contextual rápido, gerenciar docks, editar estilos ao vivo) e, se der certo, enviar melhorias para a comunidade.

This repository tests whether FreeCAD is viable for customizing the interface (hiding docks, applying QSS, quick context menu, managing docks, editing styles live) and, if it works well, contribute improvements to the community.

O que está neste repositório What is in this repository

ui_lab_probe.py

ui_lab_probe.py

Script de "laboratório" de UI dentro do FreeCAD: lista docks, aplica layout/QSS, menu rápido (Ctrl+Shift+Space) e restaura o estado original. Nunca é modificado.

UI laboratory script inside FreeCAD: lists docks, applies layout/QSS, quick menu (Ctrl+Shift+Space) and restores original state. Never modified.

ui_lab_app.py

ui_lab_app.py

Aplicação real de UI/UX (não só um teste): janela com abas de Docks, QSS/Estilo e Info/Controle, log integrado e ícone programático.

Real UI/UX application (not just a test): window with Docks, QSS/Style and Info/Control tabs, integrated log and programmatic icon.

Instalação rápida Quick installation 

cd freecad-ui-ux-experiment
uv sync                 # dependências de dev (pytest) / dev dependencies (pytest)
uv sync --extra window  # + PySide6 (app e testes de janela / app and window tests)
uv run pytest -q        # rodar testes / run tests
./run.sh app            # executar o app real (standalone / standalone app)

O projeto usa uv para dependências e mise para fixar o Python 3.11.

The project uses uv for dependencies and mise to pin Python 3.11.

Como usar (dentro do FreeCAD) How to use (inside FreeCAD)

1. ui_lab_probe.py

1. ui_lab_probe.py

from ui_lab_probe import get_lab
lab = get_lab()
for item in lab.list_docks():
    print(item)
lab.apply_layout_and_qss()   # esconde docks + aplica QSS / hides docks + applies QSS
lab.open_quick_menu()        # menu contextual (Ctrl+Shift+Space) / context menu
lab.restore()                # desfaz tudo / undo everything

2. ui_lab_app.py (aplicação real)

2. ui_lab_app.py (real application)

from ui_lab_app import run_in_freecad
win = run_in_freecad()

Oferece três abas: Docks (mostrar/esconder docks), QSS / Estilo (editor ao vivo) e Info / Controle (recalcular documento, Fit All).

Offers three tabs: Docks (show/hide docks), QSS / Style (live editor) and Info / Control (recompute document, Fit All).
